Coffee Shop Lab

Apache Flink 2.3 · streaming SQL and native AI

A smoothie chain that is already trading: purchases and customer reviews stream into Kafka, Flink SQL enriches and windows the sales into a report, and a second job hands every bad review to an LLM with ML_PREDICT. Both land in PostgreSQL and Grafana — and the generators keep producing while you work.

Start here: the web SQL editor Flink SQL in the browser. Load the DDL files from the examples menu first, then run the queries — your session survives a reload.
Open the SQL editor → Interactive pipeline →

The labs

  1. Look at the sources Declare the Kafka and CDC tables, then read the raw purchase stream and watch a product edit in PostgreSQL arrive live. flink_sql/ddl/01_sources.sql, flink_sql/explore.sql
  2. Enrich and window the stream An event-time temporal join FOR SYSTEM_TIME AS OF transaction_time, then TUMBLE and HOP windows, building up to the shape of the sales report. flink_sql/explore.sql
  3. Write the sales report to PostgreSQL Register the dwh JDBC catalog and run job 1 straight into dwh.sales_report.purchase_report; watch the Grafana sales dashboard fill. flink_sql/jobs/10_sales.sql
  4. Summarise bad reviews with an LLM CREATE MODEL, an ad hoc ML_PREDICT, then job 2: filter, model call, parse, sink. Needs OPENAI_API_KEY. flink_sql/ddl/02_models.sql, flink_sql/jobs/20_feedback.sql
